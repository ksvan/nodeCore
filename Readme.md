# nodeCore - Core insurance system for training

This repo is an mainly AI generated core insurance system, meant for training and conceptual work around insurance for techies.

It is designed to be a headless core system covering product, price, claims core, policy, invoicing. However, UIs are to be part of the repo as well, just to make it usable and demo'able.

Everything else on design, approach etc documented in the instruction files for Codex under Doc folder.
